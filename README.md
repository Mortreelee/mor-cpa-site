# mor-cpa.co.il — האתר של MOR CPA

אתר סטטי (HTML/CSS/JS) שמתארח ב-GitHub Pages. אין שרת ואין מסד נתונים.
פניות מהבוטים ומטופס יצירת הקשר נשלחות למייל דרך סקריפט בחשבון ה-Google של העסק (בלי שירות חיצוני). הבוטים עצמם רצים באותו סקריפט.

## העמודים

| כתובת | מה יש שם |
|---|---|
| `/` | עמוד הבית: הפתיח עם הרקע החי, מה אנחנו עושים, באיזה שלב אתם, אודות (עם הגרף החי), שאלות, יצירת קשר |
| `/hechzer-mas/` | החזרי מס: מי זכאי, איך זה עובד, שאלות |
| `/prisha/` | פרישה וקיבוע זכויות: התרחישים, במה אנחנו עוזרים, מתי לפנות, שאלות |
| `/dochot/` | דוחות שנתיים |
| `/bdika/hechzer/`, `/bdika/prisha/`, `/bdika/atzmai/` | שלושת הבוטים |

## איך עורכים — חשוב

**לא עורכים את קובצי ה-`index.html` ישירות.** הם נבנים מתבנית:

- `_build/layout.html` — הכותרת, התפריט והתחתית, משותפים לכל העמודים
- `_build/pages/*.html` — התוכן של כל עמוד
- `_build/build.py` — רשימת העמודים והתפריט

אחרי כל שינוי מריצים:

```
python _build/build.py
```

הסקריפט כותב מחדש את כל העמודים ואת `sitemap.xml`.
GitHub Pages לא מפרסם תיקיות שמתחילות ב-`_`, כך ש-`_build` לא עולה לאתר.

**להוסיף עמוד** (למשל מחשבון): קובץ תוכן חדש ב-`_build/pages/`, שורה ב-`PAGES`
ב-`build.py`, ואם צריך גם שורה ב-`NAV`, ואז להריץ.

## הבוטים

- `assets/bot.js` — הנגן. **עץ השאלות לא נמצא באתר ולא במאגר**: הוא רץ בסקריפט בחשבון
  ה-Google של העסק. הנגן שולח את המסלול שהגולש עבר, ומקבל רק את המסך הבא.
  בסוף הבוט, הסקריפט עצמו שולח את הפנייה למייל.
- העמודים `bdika/*` מציינים את שם הבוט (`data-bot="hechzer"` וכו').
- מקורות הבוטים והקוד של הסקריפט שמורים במחשב, מחוץ למאגר.

## מייל וּוואטסאפ

`assets/config.js`:

- `mailEndpoint` — כתובת הסקריפט (מסתיימת ב-`/exec`). דרכה נשלחות הפניות מהטופס, ודרכה רצים הבוטים.
- `whatsapp` — מספר הוואטסאפ, בפורמט בינלאומי בלי `+`.

## עיצוב

כל הצבעים מרוכזים בראש `styles.css` ב-`:root`. `--accent` הוא המנטה, `--accent-2` הזהב.
