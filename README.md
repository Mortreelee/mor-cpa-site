# mor-cpa.co.il — האתר

אתר סטטי (HTML/CSS/JS). אין שרת, אין מסד נתונים, אין תלות בשום פלטפורמה.
אפשר לפתוח את `index.html` בדפדפן ולראות הכל.

## הקבצים

| קובץ | מה יש בו |
|---|---|
| `index.html` | כל התוכן והטקסטים של האתר |
| `styles.css` | כל העיצוב. הצבעים מרוכזים בראש הקובץ ב-`:root` |
| `script.js` | תפריט מובייל, בודק הזכאות, טופס יצירת הקשר |
| `assets/portrait.jpg` | התמונה בפתיח (1200×1500, חתוכה ליחס 4:5) |
| `assets/portrait.svg` | מציין מקום ישן — לא בשימוש, אפשר למחוק |
| `assets/favicon.svg` | האייקון שמופיע בלשונית הדפדפן |

## שינויים נפוצים

**להחליף את התמונה** — לדרוס את `assets/portrait.jpg` בתמונה חדשה.
היא צריכה להיות ביחס 4:5 (אנכי), למשל 1200×1500, אחרת היא תיחתך אוטומטית
במרכז. אם החיתוך לא מוצלח — אפשר לכוון אותו ב-`styles.css` בשורה
`.portrait img{ object-fit:cover }` בעזרת `object-position`.

**לשנות את צבע האתר** — בראש `styles.css`, לשנות את `--accent` (כרגע ירוק־אזמרגד `#0E5D52`).
כל הכפתורים, הקישורים והאייקונים יתעדכנו יחד.

**לשנות מספר טלפון / וואטסאפ** — המספר מופיע בשלושה מקומות ב-`index.html`
(קישור הטלפון, כפתור הוואטסאפ, הכפתור הצף) ובמשתנה `WA_NUMBER` בראש `script.js`.

**להוסיף או להסיר שאלה בשאלות הנפוצות** — בסקשן `#faq` ב-`index.html`,
להעתיק בלוק `<details>` קיים ולערוך.

## טופס יצירת הקשר

כרגע `FORM_MODE = 'whatsapp'` ב-`script.js`: לחיצה על "שליחה לבדיקה" פותחת
וואטסאפ עם כל הפרטים מוכנים. עובד מיד, בלי שום הגדרה.

כדי שהפניות יגיעו למייל במקום:

1. אם האתר מאוחסן ב-**Netlify** — הטופס כבר מסומן ב-`data-netlify="true"`,
   והפניות יופיעו בלשונית Forms בלוח הבקרה.
   אם הוא מאוחסן במקום אחר — לפתוח חשבון ב-**Formspree** ולהוסיף לטופס
   `action="https://formspree.io/f/הקוד-שקיבלת"`.
2. לשנות ב-`script.js` את `FORM_MODE` ל-`'server'`.

## העלאה לאוויר

האתר הוא קבצים סטטיים, כך שכל שירות אחסון סטטי יעבוד. החינמיים והפשוטים:
Netlify, Cloudflare Pages, Vercel. בכולם גוררים את תיקיית `site` לתוך הדפדפן,
ואז מחברים את הדומיין `mor-cpa.co.il` דרך הגדרות ה-DNS.

⚠️ לפני העלאה לאוויר — להחליף את התמונה הזמנית ואת פרטי הקשר אם השתנו.

## הצ'אטבוט (Treelee)

בדיקת הזכאות באתר מופנית לבוט של Treelee — הסקשן `#check` באמצע הדף.

**להגדרת הקישור**: בראש `script.js` יש משתנה אחד:

```js
var CHAT_URL = '';   // למשל: 'https://treelee.ai/bot/<token>'
```

ברגע שממלאים אותו, כל הכפתורים באתר שמסומנים `data-chat-link` מקבלים
את הכתובת אוטומטית. כרגע יש שניים — "לתחילת הבדיקה" בסקשן הבדיקה,
ו"להתחלה" בשלב 1 של תהליך העבודה.

כל עוד `CHAT_URL` ריק, הכפתורים מפנים לוואטסאפ, כדי שלא יהיה באתר
קישור מת. `CHAT_NEW_TAB` קובע אם הצ'אט נפתח בלשונית חדשה.

### הזרימה שהאתר מתאר

1. המבקר עונה על הצ'אט (2–3 דקות, בלי מסמכים)
2. אם עולה זכאות — יצירת קשר בוואטסאפ
3. בקשת המסמכים, לפי התשובות שניתנו בצ'אט
4. הגשה לרשות המסים ומעקב עד לקבלת הכסף

### להטמיע את הבוט בתוך הדף במקום לקשר אליו

בתחתית `index.html`, לפני `<script src="script.js">`, יש בלוק הערה מסומן
לקוד ההטמעה. אחרי שמוסיפים אותו, כדאי להוסיף `class="has-chatbot"`
לתגית `<body>` — כך הכפתור הצף של הוואטסאפ יזוז למעלה ולא יסתיר את הצ'אט.
